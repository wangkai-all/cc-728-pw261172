# 矿物样品成分分析页

纯静态 ES Module 应用（无构建步骤、无运行时依赖），基于**成分数据分析（CoDA）**
比较矿物样品的配方关系，而不是绝对称样量。

## 运行

```bash
# 任意静态服务器均可（ES Module 不支持 file:// 直接打开）
python3 -m http.server 8000
# 或 npx serve .
```

测试：

```bash
npm test          # 纯数学与分析管线（26 个，无外部依赖）
npm run test:dom  # jsdom 页面交互冒烟（需先 npm install）
```

- `test/math.test.js`：闭合、CLR、Aitchison 距离、Jacobi 特征分解、MDS、UPGMA、ARI 的数学性质
- `test/analysis.test.js`：零值三分类、支持集合分组、替换重闭合、子成分重算、稳定性
- `test/dom.smoke.test.js`：jsdom 驱动真实页面的完整交互冒烟（需 `npm i jsdom`，仅开发期）

## 核心方法

| 概念 | 处理 |
|---|---|
| 尺度不变性 | 距离定义为 d<sub>A</sub>(x,y) = ‖clr(x)−clr(y)‖₂，整组读数同乘任意正倍数时差为 0，不依赖浮点重闭合 |
| 闭合 closure | x → x / Σx，全部比较在单纯形上进行 |
| CLR | clr(x)<sub>i</sub> = ln(x<sub>i</sub> / g(x))，分量和恒为 0；成对比较中每个成分的 CLR 差直接说明该成分比例向谁倾斜 |
| 聚类 | UPGMA 层次聚类（类平均法），叶序与距离热图对齐；可切 k 簇 |
| 二维布局 | 经典 MDS（PCoA），Jacobi 求双中心距离矩阵的特征分解 |

### 零值三分类（原始测量语义，分析端永不覆盖）

1. **确零 `zero`**：成分确实不存在。进入样品的**支持集合**判定，绝不参与加常数替换；
   不同支持集合的样品分开成组，不混入同一总榜。
2. **低于检测限 `bdl`**：保留检测限 DL，按显式规则替换为 `DL × δ`
   （δ 可在 0.25 / 0.5 / 0.65 / 1.0 间切换或自定义），**替换后重新闭合到总和 1** 再做 CLR。
3. **缺失 `missing`**：未测，不替换、不进支持集合。

### 可比较性规则

- **同支持集合**：在全部支持成分上做完整 Aitchison 距离。
- **不同支持集合**：仅在两份样品的**共同正成分**上重新闭合做子成分比较，界面明确标注
  降维事实与各自独有成分；共同正成分 < 2 时判定**不可直接比较**。
- **删除成分**：在保留成分间重新闭合，距离矩阵、聚类、PCoA 全部从零重算，不沿用旧距离。
- **稳定性面板**：在四个 δ 下各重建一次管线，用 Spearman ρ（距离序）、ARI（分组划分）、
  逐对距离 CV（绝对漂移）回答"换替换量分组会不会变"。

## 本地样本如何覆盖验收场景

| 样品 | 设计意图 |
|---|---|
| S1 花岗岩 A / S2 稀释复测 | 全部读数精确减半 → **总量不同、比例相同**，距离恒为 0 |
| S4 玄武岩 C / S5 浓缩读数 | 全部 ×1.25（总量 124）→ 同上，距离 0 |
| S1 / S10 富硅矿浆 | wt% 与 mg/kg **不同单位**、配比完全相同（DL 等比换算）→ 距离 0 |
| S1 / S3 花岗岩 B | 总量接近（99.55 vs 99.45）但配比不同 → **总和都为一、关系明显不同**，距离显著 |
| S6 灰岩 / S7 白云岩 | K₂O 确零、Na₂O 缺失，自成支持集合组（2 份，6 成分） |
| S8 橄榄岩 | K₂O 确零但其余齐全，第三个支持集合组（演示单成员组与跨组受限比较） |
| S9 平行复检 | S1 + 测量噪声，聚类时与 S1 同簇 |
| 各样品 TiO₂ | BDL 读数，δ 切换时替换值/闭合份额实时变化 |

## 目录

```
index.html          页面结构
css/styles.css      明/暗双主题设计令牌
js/math.js          纯数学层（无 DOM 依赖，可独立测试）
js/analysis.js      零值分类、支持集合、替换重闭合、成对比较、稳定性
js/charts.js        SVG 热图/树状图/PCoA/发散条形图/构成段条
js/data.js          本地样本与成分元数据（只读事实层）
js/app.js           状态与渲染；任何参数变化整体重建管线
test/               Node 测试
```

## 数据模型要点

每个读数保留 `{ status, value, detectionLimit }` 四态结构；替换值、闭合值、CLR 只存在于
分析状态对象上，原始 `SAMPLES` 在测试中被断言不被修改。单位记录在样品级并在数据表与
样品表中展示。
